# Waveform & Observed Entity Simulator  
### SEFI/DEFI Geometric Field Engine

This project demonstrates a geometric interpretation of field behavior using:

- **SEFI** — Single Entity Field Interpretation (global field geometry)  
- **DEFI** — Dynamic Entity Field Integration (localized distortion)  

The waveform represents the global field mode.  
The draggable entity represents a localized distortion.  
As the entity approaches the waveform, curvature increases, tension rises, and when tension exceeds a threshold, the field collapses into a new stable configuration.

## Features
- Real-time waveform rendering  
- Draggable observed entity  
- SEFI/DEFI geometric tension model  
- Collapse detection  
- Adjustable parameters  

## Files
- `Home.jsx` — main UI  
- `WaveformSimulator.jsx` — canvas + rendering  
- `ControlSlider.jsx` — UI sliders  
- `SEFIDEFI_PhysicsEngine.js` — geometric physics engine
